## Workflow routing

**Song / music / jingle:** approved topic/Club facts → editorial position/humor if needed → Music Sound lane → immutable lyric version → recipe → actual recording/review → selected master → Studio context if visual → platform/site placement after proof.

**Spoken commentary / audio essay:** approved factual/editorial text and public policy here → performance script + delivery notes in music repo → voiced render only with real voice/profile consent → verified release. Prose editorial authority is **not** relocated.

**Visual-first/poster:** approved Design Canon v10 stays the priority; music may add soundtrack only after exact Work/recording and rights are chosen. Music cannot redefine typography, illustration, colors or Canvas schema.

**Game/Logic & Awareness:** project-specific local semantics and sound always win over the generic club proposal. A track fitting a Battle game does not become the Club theme.

**Published** is not the same as **APPROVED**; a URL proving a Suno public page does not prove audio was selected for official Club use, an identical upload to YouTube, or that a website embeds it.

## Decision before promoting the sound canon
Review identity across DC-S01..DC-S06, listen to selected actual song versions, check source rights, human tone/brand fit, and specify which surface each candidate represents. Record owner approval, evidence, Work ID / Suno UUID and a dated new approved version in the music repo. Only then update the reference pointer (below); never silently edit v10 or editorial candidates.
