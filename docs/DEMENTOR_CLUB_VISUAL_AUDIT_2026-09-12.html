03 / FINDINGS

Необходимые правки — по приоритету.

P0

Merch entity set расходится между HTML, assets и runtime mapping.

Public catalog имеет четыре продукта, в production tree есть изображения для SH-DEM-04, но tracked canonical JSON records существуют только для SH-DEM-01..03.

Риск: четвёртая карточка может исчезать или получать непредсказуемое состояние после runtime hydration.

Правка: один canonical SKU manifest, explicit key mapping и одинаковый entity set для HTML/build/runtime/data fixture.

Guard: G6 обязан проверять exact visible product count и ожидаемый набор SKU.

P0

Merch runtime способен вернуть технический fallback вместо публичной цены.

Tracked records 01–03 имеют salesState:not_open и priceEur:null. Static copy больше не показывает PRICE / TBD, но data-driven rendering всё ещё должен явно запрещать этот fallback.

Правка: неизвестная цена не рендерится как технический placeholder. Visitor-facing UI использует согласованный public state без внутреннего field naming.

Boundary: это не разрешение checkout/commercial Result — только консистентность presentation contract.

P1

Home Fuengirola имеет более одного CSS owner.

Canonical route stylesheet владеет принятой композицией, но global visual layer всё ещё содержит suppressed pseudo-owner.

Правка: перенести оставшиеся необходимые declarations к canonical owner, доказать отсутствие визуального drift и удалить legacy pseudo-owner вместе с suppressor rules.

P1

Home event stylesheet загружается двумя путями.

Один и тот же behavior не должен одновременно приходить через import chain и direct page link.

Правка: оставить ровно один load path. Добавить contract assertion на duplicate stylesheet ownership.

P1

dementor-relations-v1.js остаётся глобальным presentation generator.

Runtime DOM mutation может снова создать entity relation, которая уже существует статически или строится route-level кодом.

Правка: relation должна формироваться build-time/static там, где данные известны; если runtime нужен — модуль должен быть route-scoped и idempotent.

P1

Community/Ink runtime содержит dead selector branches.

Новые страницы уже перешли на актуальный semantic hero, но legacy targeting продолжает жить в runtime слоях.

Правка: active route responsibility manifest; не загружать Ink/runtime styles и mutation code на route без активного presentation owner.

P1

Visual regression coverage неравномерный.

Home Fuengirola имеет reference hashing/screenshot guard, остальные target routes в основном защищены DOM counts и geometry assertions.

Правка: добавить stable region screenshots минимум для Events header/programme, Fuengirola hero, Community hero и Merch catalog на 1440 и 390.

P2

Version/date-stamped CSS и exact-byte asset aliases продолжают накапливать debt.

Repository всё ещё содержит about-v1/v10, home-20260828, ink-layout-v2+tuning, community responsive fixes и duplicate raster aliases.

Правка: не удалять по имени. Сначала built/runtime ACTIVE / COMPAT / DEAD manifest; удалять только proven DEAD и только после обновления references.
