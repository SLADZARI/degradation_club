# Производственный workflow

## Статусы материала

`IDEA → DRAFT → SCRIPTED → VISUAL → REVIEW → READY → PUBLISHED → ARCHIVE`

## Карточка материала

Для каждого поста создаётся Markdown-файл в `posts/`:

- ID;
- рабочее название;
- рубрика;
- формат;
- текст/слайды;
- визуальный замысел;
- CTA;
- статус;
- дата публикации;
- ссылка на Drive;
- ссылка на опубликованный материал.

## Нейминг

`LA-###-slug.md`

Примеры:

- `LA-001-first-signs-of-logic.md`
- `LA-002-cunning-of-facts.md`
- `LA-003-critical-thinking-symptoms.md`

## Редакционная проверка перед визуалом

1. Одна публикация — одна мысль.
2. Один слайд — один тезис.
3. Нет объяснения шутки внутри шутки.
4. Формулировки звучат как официальная инструкция.
5. Панчи короткие и могут жить отдельно.
6. Визуал не дублирует весь текст, а добавляет второй слой.
