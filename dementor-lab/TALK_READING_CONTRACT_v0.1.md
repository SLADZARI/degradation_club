# DEMENTOR LAB — TALK Reading Contract v0.1

Status: APPROVED FOR QA

## Principle
Conversation owns the TALK viewport. Technical evidence remains available on demand and must never compete with reading the exchange.

## Mobile hierarchy
1. Scenario + current objective.
2. Compact arena + per-side metrics.
3. Scrollable conversation history as the largest reading surface.
4. `ПОЧЕМУ ТАК?` for causal/metric evidence.
5. Primary PAUSE / RESUME / NEXT action.

## Conversation
- Full encounter transcript remains scrollable.
- Player can review older turns during the encounter.
- Touching or scrolling history pauses AUTO.
- Speaker names remain visible inside bubbles.
- Dialogue text uses the actor gender from visual identity; feminine characters must not emit masculine agreement forms.

## Diagnostics
- `TRACE` does not live beside the primary TALK action.
- Technical TRACE is inside the opt-in diagnostic layer.
- Opening diagnostics pauses AUTO.
- Exact metric deltas and memory remain evidence, not primary game copy.

## Invariant
`read the conversation first → inspect why only when wanted`
