# DEMENTOR LIVE — Decision Register v0.1
Дата 2026-10-17. Статус BASELINE, CANON REVIEW; не все главы утверждены.

## Политика статусов
APPROVED: только прямое решение пользователя или реально принятый дизайнерский раздел; PROPOSED: рабочее предложение; TEST: числа балансировки; OPEN: предмет будущего утверждения; IMPLEMENTED: код существует; VERIFIED: тесты прошли. Из утверждения GDD не следует реализация.

## PROPOSED architecture
DL-P01. PAPER как денежный баланс и PAPER_SHEET как физический товар; отдельный CARDBOARD.
DL-P02. Городские job transfers через казначейство, а не бесконтрольная валюта из фабрики; эмиссия выделена отдельно.
DL-P03. Сервер авторитетен для собственности, денег, запасов, торговли, боевых результатов, таймеров.
DL-P04. Логическое разделение WORLD/LAND/BUILD/RESOURCE/FARM/WATER/PRODUCTION/ECONOMY/TIME/WORK/MARKET/SOCIAL/COMBAT/TRANSPORT/CHARACTER.
DL-P05. Ресурсные контейнеры, водная сеть графом, recipes + stages, offline deterministic event order, escrow для торговли и работы.
DL-P06. GAMEPLAY допускает одиночную социально-хозяйственную игру без принудительного PvE; первоначальный кооп 2 человека TEST.
DL-P07. Публичные торговые витрины на границе участка без открытия приватной зоны.
DL-P08. LAND status многомерен: territory/ownership/development/availability.
DL-P09. F2P cosmetic-first без pay-to-win; возрастные правила ещё открыты.
DL-P10. Персонаж в восьми игровых направлениях под одной выбранной камерой, но создание четырёх авторинговых ортографических исходников как intermediate — возможный способ производства, не равный уже готовым 8 ракурсам.
DL-P11. DRAFT → REVIEW → APPROVED → IMPLEMENTED → VERIFIED и версионирование отдельных правил.
