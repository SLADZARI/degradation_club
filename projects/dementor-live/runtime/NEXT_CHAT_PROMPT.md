# Сообщение для продолжения

Продолжаем существующий Dementor Live из этой папки или приложенного ZIP. Сначала прочитай AGENTS.md, START_HERE.md, CURRENT_STATE.md и docs/REQUIREMENTS.md. Не начинай проект заново. Сохрани текущие изменения и три бумажных референса.

Используй терминал для локальных файлов и проверок, а уже подключённые GitHub/Google Drive — для существующей документации. Сначала проверь доступность инструментов в этом чате. Не создавай новые аккаунты, remote-репозитории, платные сервисы или публичный деплой. Не меняй глобальные разрешения плагинов.

Рабочая среда подготовлена: npm run doctor, npm run check, npm start, npm run pack. Минимальный slice уже прошёл модельные, HTTP/SSE и реальные браузерные проверки двух независимых клиентов; смотри актуальные результаты и ограничения в CURRENT_STATE.md. Не путай их с прежним HANDOFF, где проверки ещё не были выполнены. После изменения runtime проверять новое состояние, а не ссылаться на старый PASS.

Покажи краткое состояние и ближайший шаг. Затем выполняй именно моё новое поручение. Если я прошу закончить базовый slice, продолжи с интеграционных и браузерных проверок, исправляй фактические проблемы и сделай интерфейс аккуратным. Не превращай тестовые числа из config.mjs в согласованный канон и не расширяй игру до PvE/производства/авторского голосования прежде базового пути.

Последнее расширение: игра двух устройств в одной локальной сети, затем строительство общественной кузницы после площади. Адрес Mac при настройке — http://172.20.10.3:4173; при смене сети смотреть адрес в выводе npm start. Сохранённый мир не сбрасывать. Производство кузницы пока отсутствует. Сетевой smoke-тест: npm run test:lan. Подробности нового объёма — CURRENT_STATE.md.

Последнее расширение: городской склад с дешёвой приёмкой личной древесины/камня, выкладывание/подбор ресурсов и доска работ с курьерской доставкой городского груза в мэрию. Читай docs/CITY_WAREHOUSE.md; test:city проверяет этот путь двумя браузерами в отдельном мире. Личный и городской груз не смешивать, повторно городской ресурс не оплачивать. Сохранённый мир пользователя не сбрасывать.

Последнее расширение: камера всегда следует за героем, ☷ «Места города» даёт маршруты к дальним целям. В готовой кузнице изготовляются инструменты из личных 2 дерева/2 камня (48 прочности), магазин продаёт дорогие варианты по 180 PAPER (160 прочности). Бесплатные стартовые имеют 16; их выдача не ремонтирует улучшенные. Метаданные и износ сохранены. Читай docs/TOOLS_AND_CAMERA.md; test:tools использует явные изолированные фикстуры готовой кузницы/средств и не доказывает заработок цены.

Последнее исправление: рывки постоянной камеры. Клиент интерполирует снимки позиций с коротким буфером, герой и камера используют общую визуальную позицию; авторитетная симуляция не менялась. Не возвращай прямое view.cx=me.x из каждого кадра: сетевые координаты приходят около 10 раз/с. Подробности и воспроизводимый замер — docs/PERFORMANCE.md и npm run test:performance.

Последний игровой цикл: третий проект — мост после кузницы. Складские курьеры теперь могут везти городской материал на мост, с резервом потребности и оплатой только перевозки. После завершения реально открывается переправа на другой берег с новыми деревьями/камнем/ягодами; истощение сохраняется. Читай docs/BRIDGE_AND_EXPLORATION.md и reports/bridge.json. Сохраняй плавную камеру и старый мир; частные дома/огороды пока следующий объём.

Обновление 18 октября: добавлены life.mjs и public/life-ui.js — сцены участка/интерьера, конечная расчистка, палатка, сундук, грядки, семена и вода, урожай, P2P сделки, гости и Доска воров. Читать docs/FIRST_HOME_PLAYABLE.md и последнюю запись CURRENT_STATE.md. Не считать полный набор предложений FIRST HOME завершённым: пока нет FOOD batches/порчи, отдельных HELP_GARDEN/HARVEST_FOR_OWNER, временных/количественных permits, частного найма, свободного строительства, фабрик и городов/ботов. Не сбрасывать data/world.json.

Новые объекты площади: plaza.mjs / public/plaza-ui.js / public/music/*.mp3. Пьедестал платит50 один раз за текстовую идею памятника. Автомат — общий трек2, заявка1, локальное включение звука, загрузка MP3 у сервера через localhost; пользовательские файлы в data/music вне ZIP. Читать docs/PLAZA_OBJECTS.md и последние проверки CURRENT_STATE.md. MP3-кодировщик временный, игра использует только Node built-ins.

Физическая Доска воров на площади: plaza.config.objects id theft-board, тип plaza; клиент открывает режим thefts. Не дублировать журнал краж. server MP3-near ищет jukebox по ID, не по индексу объектов. Общие paperBox/paperHouse/paperTent/paperBoard/paperBench задают один бумажный объём для зданий/мебели, без изменения сетки/коллизий. Проверки и визуальные фикстуры в reports/axonometry.json, test/axonometry.cjs.
