## Реальное состояние

С нуля создан изолированный локальный браузерный прототип; никакой код Battle/Robo/клубного сайта не использован. Новый удалённый GitHub-репозиторий не создавался. Удалённая документация в известной ветке сохранена; тестовые числа прототипа в согласованное ядро не добавлялись. Запись о локальном прототипе в удалённых индексах **пока не добавлена**: работа остановлена пользователем до завершения реализации и QA.

В коде присутствуют:

- Node.js HTTP-сервер, авторитетное состояние, SSE для отдельных клиентов, обработка действий и движения, проверка расстояния, сохранение JSON через временный файл и переименование.
- Общий мир с рекой и непроходимой переправой, палаткой, инструментами, площадью, участками, конечной древесиной и камнем, возобновляемой едой. Кузница и мост — только будущие проекты.
- Индивидуальные деньги, инвентарь и инструменты; груз, износ/бесплатная замена, физическая сдача, выплаты из города, три строительных этапа с расходом ресурсов, покупка одного участка.
- Голод только онлайн, замедление, дух с запретом работ, самовосстановление ягодами даже с полным грузом, помощь едой другого жителя, бег с расходом и восстановлением сил, локальный чат.
- Новый клиентский UI на Canvas и HTML/CSS: карта на первом плане, компактные плавающие панели, активная задача, контекстное действие, инструменты/груз, статусы, чат; персонажи рисуются отдельно от карты в духе блоковых референсов. Интерфейс **написан, но не просмотрен в браузере**.

## Что ещё не проверено и что отсутствует

- НЕТ доказательства полного пути в браузере, синхронизации двух настоящих браузерных клиентов, отсутствия ошибок браузерной консоли, адаптивности, удобства или визуальной точности UI. Скриншота самого приложения нет. PNG в references — концептуальные ориентиры, не результаты QA.
- HTTP/SSE-интеграционный набор подготовлен в `test/integration.mjs`, но **не запускался**. Он сам создаёт отдельный тестовый сервер на 4178 с временным хранилищем и двумя SSE-подключениями; интенсивные случаи используют явные фикстуры. Возможные ошибки самого набора пока не исключены. Даже его успешный запуск не заменит браузерный проход.
- При передаче заметна конкретная проблема неподтверждённого интеграционного сценария: после последних 40 единиц узел ресурса уже пуст, но проверка дополнительной добычи в неполной последней партии ожидает успех. Следующему чату нужно учесть исчерпание узла в этом утверждении. Сам код игры корректно запрещает добычу из пустого узла; тесты модели это проверяют. Новая правка тестового набора сейчас не делалась по просьбе остановить разработку.
- Реальная перезагрузка/рестарт работающего сервера с проверкой денег, участка и стройки пока не проверялась. Пройден только тест сериализации/восстановления модели.
- Автоматическая система разрешений отказала в запуске browser QA: достигнут лимит использования проверки разрешений. Это не заключение о небезопасности. Повторный обход через другой инструмент не предпринимался. Простой HTTP-запрос из песочницы также не прошёл (`fetch failed`). Нужно продолжить проверки после восстановления разрешённого доступа, не утверждать PASS заранее.
- Не реализованы строительство собственного дома/кузницы/моста, производство, голосование и авторские здания, PvE, монетизация, внешние аккаунты, публичный деплой. Они не нужны до завершения базовой цепочки.

## Процессы и данные в точке передачи

Рабочий сервер был остановлен через управление его собственной exec-сессией перед упаковкой. Автоматический браузер не запускался. В архиве нет запущенных процессов; адрес ниже заработает после нового запуска.

Обычный сервер: `http://127.0.0.1:4173`, только на этом компьютере. Тестовый интеграционный сервер: 4178, создаётся тестовым скриптом. Открытие HTML напрямую не работает.

Состояние сохраняется при работе в `data/world.json`. data исключён из пакета из-за локальных идентификаторов сессий; архив начинает чистый мир. В момент передачи на основном сервере не было создано ни одного игрового жителя: браузерный вход не состоялся. Вход текущей вкладки хранит только токен идентичности в `sessionStorage`; реальный мир и расчёты находятся на сервере, не в localStorage. Закрытие вкладки снимает online и прекращает голод. Игровой аккаунт с паролем/защита для публичного сервера пока не реализованы.

## Запуск после распаковки

Проверенная среда исходного компьютера: macOS, Node.js **v22.14.0**, npm **10.9.2**. Приложение не зависит от внешних npm-пакетов; требуется Node 22+. Также на исходном компьютере был доступен отдельный bundled Node v24.19.0. Для разработки в обычном чате достаточно современного Node.

```sh
cd dementor-live-prototype
npm test
npm start
```

Затем открыть `http://127.0.0.1:4173`, ввести имя. Для второго настоящего игрока открыть независимую вкладку с другим именем или кнопку `?` → «Открыть вход второго игрока». Перезагрузка своей вкладки сохраняет жителя; новая независимая вкладка создаёт нового. Повторный запуск сервера читает его прежний JSON.

```sh
npm run test:integration
```

Последняя команда требует разрешения на локальные сокеты. Никаких сервисов покупать и разворачивать не требуется. Если 4173 занят: проверить конкретный старый процесс и корректно завершить его либо задать `DEMENTOR_PORT=4174 npm start`; нельзя останавливать произвольные процессы.

WASD/стрелки — движение; Shift — бег; щелчок на земле — путь; E — действие/удержание для повторения; 1/2 — топор/кирка; F — еда; Enter — чат; Escape — отмена. Кнопки масштаба и центрирования справа. Всё описано и в README.
