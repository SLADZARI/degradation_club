# Обитель Габеля — P0: неполные цепочки и безопасный обход

Дата: 2026-10-20. **Статус: отдельная ветка, НЕ production, автоматические модельные, HTTP/SSE и Chromium desktop/mobile smoke пройдены; production НЕ обновляли.**

## Жёсткие правила
- Общие CharacterId, кошелёк PAPER, строительство, земля, города, предметы, перемещение и сохранения Dementor Live остаются без замены.
- Не придумывать новых вопросов, NPC, веток и наград. Исходные имена/первичные вопросы — только из Obitel Base, лист «42 карты-поля».
- На незаконченной карте показывать оригинальный вопрос, затем «Продолжение сценария пока не завершено». Не интерпретировать `ready` как готовый диалог.
- `Хочу продолжить` → записать `player.obitel.continuationRequests[cardId]={at,status:'pending'}`; повторное нажатие не создаёт новую заявку.
- `Пропустить` → только `skippedAt`. Никаких штрафов, нового текста, токенов, выплат и начисления ачивок.
- `Сохранить ответ` → записать `answers[].{questionId,text,at}` в текущего игрока, `contentStatus='partial'`; не открывать гору, не переводить карточку в completed.
- После возврата в общий мир данные остаются в сохранении персонажа. Просмотр всех текстов ответов в UI профиля — отдельно, НЕ P0.
- Не выполнять платёж и не внедрять покупку городов за реальные деньги в этом пакете. Существующие правила экономики не трогать.

## Физически доступный срез P0
Вход из большого мира `obitel-zen-entry` в отдельную сцену `obitel-zen` и безопасный обратный выход `obitel-zen-exit`.
7 оригинальных точек, у каждой только один первичный вопрос:
1. OB-C01 — Аракул
2. OB-C02 — Сумрачный Лес
3. OB-C03 — Осязание
4. OB-C04 — Город Мастеров
5. OB-C05 — Тест
6. OB-C06 — Леопард
7. OB-C07 — Внутренняя Цитадель

Даже если строка источника `ready`, все семь карточек сейчас имеют `contentStatus:partial`, `completed:false`; вторые/третьи уровни ещё требуют редакции оригинальных диалогов.

## Acceptance на ветке
1. Семь карточек отображаются на поле ZEN; любой игрок может дойти до каждой и нажать E.
2. Первичный вопрос точно соответствует источнику; пустой или более 500 символов ответ отвергается.
3. «Пропустить», «Сохранить», «Хочу продолжить» не вызывают исключений; заявка повторно не размножается.
4. Ответ привязан к CharacterId/карте/времени; повтор с тем же `requestId` не создаёт дубль.
5. Рестарт мира и выход-вход не удаляют ответ и заявку; другое лицо не получает их через snapshot.
6. Не меняются wallet, treasury, участки, города, инвентарь и права мэра.
7. Незавершённая карта не выдаёт ачивку и не открывает гору.
8. Все ранее работающие маршруты city ⇄ museum / farlands остаются рабочими.
9. `npm run check`, `npm test` с `obitel-p0.test.mjs`, `npm run test:integration`, Chromium browser `test/obitel-browser.cjs` — **PASS** по GitHub Actions [#39453040926](https://github.com/SLADZARI/degradation_club/actions/runs/39453040926) (изолированный временный мир, desktop 1280×800 / mobile viewport 390×844).\n10. Durable shutdown→real file restart с ответами Обители, мультиплеерная изоляция двумя клиентами, реальный iOS Safari, текущий production state — **NOT RUN**. Требуют отдельного release gate.
