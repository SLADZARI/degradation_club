# DL-GRID-02 — единая ISO30 геометрия дома и участка

**Дата:** 20 октября 2026 · **Цель:** следующий релиз Dementor Live поверх P4/P5 · **Production:** без изменений.

## Единый контракт

- Координаты предметов, игроков, целей действий и событий остаются исходными world units. Презентация в любом `scene` использует изометрию ISO30 и обратную матрицу клика.
- Ручное управление WASD/стрелками и джойстиком — относительно **экрана** (↑ ↓ ← →); к серверу отправляются координаты движения по миру. Автоматический путь уже рассчитывается по мировым координатам и НЕ вращается повторно.
- `local-geometry.mjs` содержит авторитетные прямоугольники `localFootprints(scene,home,now)` с `id,kind,x,y,w,h,height,solid`. Сервер проверяет касание радиуса 0.3, клиент получает **те же** прямоугольники в `state.homeFootprints` и использует их для поиска пути.
- Для существующего игрока, который после обновления оказался внутри препятствия, доступно **только движение наружу**, чтобы исключить softlock старого сохранения.
- `public/life-ui.js` рисует прямоугольники пола, стены, мебель, постройки и игровые предметы той же матрицей ISO30. Все непрозрачные объекты, ресурсы, предметы на земле и игроки идут через один painter queue (сортировка глубины). Подписи интерфейса отрисовываются отдельно поверх сцены.
- Пол участка и комнаты 16×16: линии сетки каждые 1 world unit, без самостоятельной прямоугольной проекции интерьера.

## Физические объекты и сценарии

| Сцена | Объект | Правило |
| --- | --- | --- |
| Участок | Палатка 6..10, 5..8 | Визуальная основа 4×3. Боковые и задняя стенки solid со стадии 2; фронтальный проход остаётся доступным, вход по существующему действию `homeUse(tent)` |
| Участок | Колодец около 14,3 | Физическое кольцо около 1.1×1.1, вода набирается из точки `well` в радиусе действия |
| Участок | Грядки | Физическая площадь 1.1×1.1 на существующих координатах; растения и рост сохраняют старые поля |
| Участок | Деревья и ресурсные узлы | Сервер и клиент используют одни координаты; дерево блокирует только после перехода в стадию роста |
| Участок | Места посадки | При создании грядки нельзя занять уже вскопанную площадку дерева |
| Комната | Сундук | 1.6×1.3, высота 0.85; короб и крышка отрисовываются с учётом подъёма |
| Комната | Кровать | 2.4×1.7, высота 0.48; матрас и подушка на поверхности, а не на полу |
| Комната | Стены | Изометрические задние стены с физической толщиной 0.36; передняя стена отсутствует, чтобы не заслонять героев |
| Любая локальная сцена | Сброшенные предметы | Небольшая изометрическая стопка по реальным `x,y`, доступ к подбору сохраняется, коллизия не добавлена |

## Совместимость и границы

Новые поля не сохраняются в `world.json`: `homeFootprints` вычисляется для актуального состояния и отправляется только в снапшоте. Старые сохранения, распределение ресурсов, прогресс строительства, валюта и прав доступа не мигрируются. **Новые свободно перемещаемые предметы мебели и строительный редактор этим пакетом не вводятся.**

## Гейты приёмки

1. `npm run doctor && npm run check && npm test` — реальная модель + синтаксис.
2. `node test/geometry-p5-browser.cjs` — реальный Chrome: ISO30, правильные W/S/A/D, обратная проекция клика, реальная физика мебели, painter depth без JS ошибок.
3. `test/local-geometry.test.mjs` — вход в палатку, огород, колодец, сундук, кровать, стены, сохранение/reload, выход из старого препятствия, запрет перекрытия деревьев грядкой.
4. Вручную: мобильный стик, pinch zoom, проход вдоль всех стен, 2 клиента на участке, последовательность войти→сундук→кровать→выйти и предмет перед/за объектом.
5. До любого production merge: безопасная цепочка **P4 → P5 → GRID-02**, backup `dementor-live-world`, QA 2 устройств. Без перезаписи `data/world.json`.

**Условие завершения:** automated CI green не означает прошедшее ручное QA на физическом мобильном устройстве.
