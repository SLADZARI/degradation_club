# Dementor Live — начать здесь

Эта папка — готовая минимальная рабочая среда для продолжения существующего прототипа обычным чатом и терминалом. Ничего устанавливать из npm для запуска игры не нужно. Требуется Node.js 22+; для локальной истории — Git.

## Три действия

1. Открой обычный рабочий чат с доступом к этой папке и терминалу. Прочитай или передай ему NEXT_CHAT_PROMPT.md. В Codex для проекта добавлен AGENTS.md с правилами работы.
2. Проверь среду и базовую логику:

```sh
npm run doctor
npm run check
```

3. Когда хочешь открыть игру:

```sh
npm start
```

Адрес после запуска: **http://127.0.0.1:4173**. Для второго жителя используй независимую вкладку или кнопку `?` → «Открыть вход второго игрока». Остановка — Ctrl+C в терминале сервера. Сервер не запускается от команд doctor/check/context/pack.

На Mac можно открыть двойным щелчком START.command или CHECK.command прямо в этой папке. Рядом с исходной папкой есть также START_DEMENTOR.command и CHECK_DEMENTOR.command. Первая запускает сервер в Terminal, вторая выполняет проверки. На другой ОС используй команды выше.

## Игра вдвоём в одной сети

Сервер уже поддерживает двух жителей в одном сохранённом мире. `npm start` теперь открывает доступ в локальной сети и показывает адрес второго устройства. Текущий адрес Mac: **http://172.20.10.3:4173**. Оба игрока могут открыть именно его и ввести разные имена. После смены Wi-Fi адрес может измениться — смотри вывод запуска.

Оставь Mac включённым и сервер работающим. На втором устройстве сервер запускать не нужно. Используйте обычную общую сеть без изоляции клиентов. Если macOS спросит о входящих подключениях для Node, разреши их для этой игры. При недоступности адреса проверь одинаковую сеть, VPN и изоляцию гостевого Wi-Fi. Настройки системы автоматически не меняются.

Управление: WASD/стрелки или нажатие на землю; Shift — бег; E — действие рядом (удержание повторяет); 1/2 — топор/кирка; F — еда. Оба собирают материалы, сдают у площадки и выполняют строительные работы. Общий прогресс виден сразу; заработок у каждого свой. Сначала строится площадь. Затем автоматически открывается общественная кузница внизу справа: сдача у левого края, работы внутри. Кузница требует 24 древесины и 24 камня; три этапа — фундамент, стены/крыша, обустройство горна. Каждый принятый вклад оплачивается отдельно. Изготовление инструментов в готовой кузнице добавлено; инструкция ниже. Существующий мир и накопленный прогресс не сбрасывались.

Для доступа только с самого Mac: `DEMENTOR_HOST=127.0.0.1 npm start`. Проверка LAN: `npm run test:lan` использует отдельный временный мир и два браузера через сетевой IP.

## Рабочие команды

| Команда | Что делает |
|---|---|
| npm run doctor | Проверяет версию Node, файлы проекта, документы, 3 референса и наличие Git; не лезет в аккаунты |
| npm run check | Проверяет синтаксис JS и модель; показывает отдельно записанные HTTP/browser-результаты при совпадении runtime; сохраняет отчёт |
| npm run context | Показывает краткое состояние и пути входных документов для нового чата |
| npm start | Запускает обычный локальный сервер; data/world.json сохраняется между запусками |
| npm run test:integration | Отдельный HTTP/SSE-набор с изолированным состоянием и независимыми подключениями |
| npm run test:browser | Два настоящих Chrome-контекста, полный базовый UI-путь и скриншоты; нужен отдельно доступный Playwright |
| npm run pack | Создаёт рядом свежий dementor-live-workspace.zip с исходниками/контекстом/референсами и проверяемым MANIFEST.json |

Игра не требует интернета или плагинов для запуска. Для работы с удалённой документацией доступны GitHub и Google Drive; в текущем чате их статус проверен как ENABLED. Их наличие и права в следующем чате проверяются отдельно. Аккаунтные секреты и настройки разрешений в пакет не входят.

Чат без инструментов доступа к файлам/терминалу может прочесть прикреплённый ZIP и обсуждать проект, но эта папка сама по себе не добавляет ему терминал или плагины. Чтобы продолжать исполнение на этом компьютере, выбирай чат с таким доступом.

## Освободить рюкзак, склад и заказы

Нажми **«Рюкзак»** рядом со счётчиками ресурсов: можно выложить одну единицу или всё на землю, затем подобрать через E. Вещи на земле доступны всем жителям.

**Городской склад** находится между нижними участками. Подойди и нажми E: склад покупает древесину/камень по 1 PAPER за единицу, дешевле прямой поставки на стройку. Освобождается рюкзак, запас появляется у города. Вместимость и свободный бюджет видны в окне.

**Доска работ** слева от палатки мэрии открывается через E. На ней перечислены текущие поставки, стройка и курьерские заказы. Доставка: возьми заказ → забери городской груз на складе → принеси к отметке «Доставка в мэрию» севернее инструментов → E. Награда — 2 PAPER за заказ; груз занимает вес, повторно продать его нельзя. Отменить полученный заказ с возвратом можно на складе. После заполнения текущей потребности мэрии соответствующие заказы исчезают.

Полные правила и временные числа: docs/CITY_WAREHOUSE.md. Проверка нового пути двумя браузерами: `npm run test:city`. Ваш старый мир продолжается без сброса.

## Камера и инструменты

Камера **всегда следует за героем**. Кнопка **☷ «Места города»** рядом с +/− показывает цели и строит к ним путь. Привязка сохраняется при любом масштабе.

После достройки кузницы выбери **«Кузница · изготовление»** в местах города или подойди к отметке под зданием и нажми E. Каждый топор/кирка требует **2 древесины + 2 камня** из личного рюкзака и получает **48 прочности**. Магазин вверху карты продаёт инструменты с **160 прочности за 180 PAPER каждый**. Стартовые бесплатные служат 16 использований. Все значения пробные.

Улучшенный инструмент не ремонтируется бесплатной выдачей. Полностью сломанный можно заменить стартовым бесплатно; текущий более прочный не заменяется более слабым. У каждого вида хранится один инструмент; покупка/изготовление заменяет его остаток. Инструменты и износ сохраняются. Подробнее: docs/TOOLS_AND_CAMERA.md. Проверка новых функций: `npm run test:tools`.

## Исправлены рывки камеры

После обновления страницы камера и герой плавно движутся между сетевыми обновлениями, сохраняя постоянную привязку. Игровая логика и ваш мир не меняются. При необходимости повторить замер: `npm run test:performance` в отдельном временном мире. Причина и числа до/после — docs/PERFORMANCE.md.

## Продолжение: мост и другой берег

После кузницы открывается **третий общий проект — мост**. Через ☷ «Места города» выбери «Приёмка моста» для сдачи ресурсов или «Стройка моста» для работы. Нужно 24 древесины, 16 камня и три этапа работ. За принятый личный вклад платит город.

На доске доступны также доставки **со склада на мост**: забери зарезервированный городской груз и сдай у приёмки моста. Оплачивается перевозка, повторной продажи городского материала нет. Так можно использовать уже проданные складу запасы.

Готовый мост открывает настоящий проход на другой берег: новые деревья, камень и ягоды можно добывать/собирать и переносить обратно. Плавная постоянная камера сохраняется. Старый мир не сбрасывается. Подробности — docs/BRIDGE_AND_EXPLORATION.md; проверка: `npm run test:bridge`.

## Новое: участок, огород и сделки · 18 октября

Обновите страницу. **Жители** — подарок/обмен/продажа рядом, с отдельным принятием соседа. **Рюкзак** — все предметы и семена, выбор количества, еда и отдельный городской груз. Там расчистка, палатка, интерьер с личным сундуком/кроватью, вода и шесть грядок для конопли/моркови. Хозяин открывает посещение и отдельно разрешает сбор. Несанкционированный сбор явно подтверждается как кража и появляется на Доске воров.

Пошаговая инструкция, пробные числа и границы: [FIRST_HOME_PLAYABLE](docs/FIRST_HOME_PLAYABLE.md). Для нового UI нужна перезагрузка обоих клиентов. Крупные системы покупки городов/ботов/фабрик и порчи еды пока не включены.

### Уточнение интерфейса: компактный рюкзак

🎒 открывает небольшую сетку предметов с эмоджи и отдельными инструментами. Выбор ячейки показывает действия. Торговля — отдельная кнопка «Жители». Семена и Доска воров — ☷ → соответствующая служба, без навигации внутри рюкзака. Можно хранить несколько топоров/кирок с независимой прочностью; выбор «Взять в руки» меняет активный экземпляр. Покупка/изготовление больше не уничтожает предыдущий инструмент. Пробный предел 12 инструментов. Подробнее docs/TOOLS_AND_CAMERA.md.

### Новое на площади: памятник и музыка

☷ → **🏛️ Пьедестал** → подойти → E → ответить, какой памятник хочется видеть. Мэрия платит **50 монет один раз** каждому жителю из свободного бюджета. ☷ → **🎵 Музыкальный автомат** → E: один общий трек за **2 монеты**, музыкальная заявка за **1 монету**. Для звука нажмите **«Включить звук города»**. Есть два оригинальных демотрека MP3; собственный MP3 хозяин сервера добавляет через окно автомата на localhost. Подробности: docs/PLAZA_OBJECTS.md.

Бумажный стиль карты восстановлен: деревья, камни, красноягодные кусты и объекты площади — геометрия/origami. Эмодзи только в интерфейсе предметов; семена конопли 🌰 и моркови 🫘 различаются. Для получения нового вида достаточно обновить страницу.

Обновление графики: склад, магазин, кузница, палатки, скамейки и бытовые предметы теперь в одной объёмной бумажной аксонометрии. На площади есть физическая **Доска воров**: ☷ → Доска воров → подойти → E. Открывает прежние записи краж; новых штрафов не вводит. `npm run test:axonometry` — визуальные сцены и взаимодействие с доской в отдельном мире.
