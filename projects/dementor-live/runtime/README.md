# Dementor Live · 0.2.0

Локальная многопользовательская бумажная игра: строим город, зарабатываем на участок, обустраиваем дом и огород, расчищаем новую землю вместе. Node.js 22+, runtime без npm-зависимостей.

Вход: [START_HERE](START_HERE.md). Состояние и границы проверки: [CURRENT_STATE](CURRENT_STATE.md). Изменения: [релиз 0.2.0](docs/RELEASE_0.2.0.md). Следующий чат: [NEXT_CHAT_PROMPT](NEXT_CHAT_PROMPT.md).

`npm start` → http://127.0.0.1:4173; сетевой адрес второго устройства показывается при запуске. WASD — идти; E — действие; 1–6 — ячейки; Q — положить ресурс; F — поесть. ☷ показывает места; задания слева сворачиваются.

Город 64×40, восемь участков. Общая экспедиция: южный указатель (31,35), E; расчистка 8 древесины и 6 камня открывает два восточных участка; (8,14) — выход. Одна конечная зона, без PvE и бесконечной генерации. Прогресс и добыча сохраняются. Для восточного берега нужен мост.

`npm run doctor` — среда. `npm run check` — синтаксис/модель. `npm run test:integration` — HTTP/SSE. `npm run test:expansion`, `test:quests`, `test:compact-panels`, `test:perimeter` — браузерные сценарии во временных мирах; отдельно нужны Chrome/Playwright. `npm run pack` — переносной ZIP с MANIFEST.json.

Реальный мир в data/world.json; не удалять/не публиковать. Сохранения, backups и секреты исключены из архива. Это локальный сервер, не постоянно доступный публичный сайт. Городская валюта только игровая, числовые параметры — прототип.

## Отдельный Ubuntu VPS — изолированный preview (18.10.2026)

Для существующего сервера с Nginx, Docker, PostgreSQL и Stage A подготовлены **только** [правила безопасной установки и отката](ops/DEPLOY_ON_OWN_VPS_2026-10-18.md) и [проверочный shell-скрипт](ops/isolated-preview.sh). Они фиксируют SHA **v0.2.0**, создают новый каталог `/srv/dementor/live-preview` и **отдельный** Docker-контейнер на loopback `127.0.0.1:14173`. Существующие сервисы, Nginx, DNS, TLS, порты 80/443/18080 и `/data` не изменяются. Этап preflight только читает состояние сервера. **Это подготовка, НЕ подтверждение фактической удалённой установки:** до просмотра результатов preflight не выполнять install, не открывать публичный домен.
