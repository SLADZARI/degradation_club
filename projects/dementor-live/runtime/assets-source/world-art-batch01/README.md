## Канон

Каждая иллюстрация — собственный редактируемый SVG с `viewBox="0 0 512 512"`, изометрическими объёмами с горизонтальными осями 30°, 2–8 крупных плоских картонных форм (объект мира сложнее маленькой иконки), приглушённые цвета, минимальное число деталей, прозрачный canvas, никаких внешних теней, надписей или внешних ресурсов. Отсутствие фона достигается SVG-авторингом, а не вырезанием из бумажного плаката. PNG всегда только из SVG.

Сохранить игровые размеры в Cube Units, footprint и порядок глубины из **серверных** `world-footprints.mjs`/`local-geometry.mjs`; картинки пока НЕ валидируют метрическую проекцию, коллизии и состояние строительства. Не заменять ими world objects без измерения anchor/footprint и тестов изометрии в браузере. Ветки Obitel и MentalHumor не считаются частью RC4.

## Автоматическая проверка

```
python3 build.py
python3 audit.py
python3 test_assets.py
```

Локальные зависимости генератора: `cairosvg`, `pillow`; требования runtime игры не меняются.

## Чего ещё не делали

Нет прямой установки в production, нет слияния игрового движка, нет browser/iPhone QA/Retina/FPS, нет художественного утверждения пользователем, нет полной сетки размеров CU, нет окончательной графики всех стадий зданий. Для крупных физических объектов нужны отдельные стадии и обрезка окклюзии с тестом глубины. Исходники представлены в отдельной ветке и архиве для дизайнерской проверки, без замены SVG/PNG текущего клиента.

**Нельзя**: `--reset-world`, запись в `world.json`, изменение героя, импорт старых неутверждённых UI-картинок, выдача тестовой сцены за рабочую игру.
