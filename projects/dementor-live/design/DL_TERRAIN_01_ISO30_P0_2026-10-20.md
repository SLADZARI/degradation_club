Это визуальный слой поверх имеющихся `landscape.tiles` и ISO30 `screen/worldPoint`, без нового типа предмета/ресурса, изменения покупки, карты и сохранений.

## Проекция, прозрачность, атлас
- Один игровой квадрат 1×1 соответствует ромбу: top `(128,0)`, right `(256,74)`, bottom `(128,148)`, left `(0,74)`.
- Каждый исходный SVG: `viewBox="0 0 256 148"`, прозрачный RGBA за пределами ромба, 2–4 крупных матовых бумажных слоя, без внешних теней, шума и подписей.
- Растровые выходы: отдельные 17 PNG 256×148 и 17 PNG 128×74.
- Основной клиентский атлас 256: один **lossless WebP**, `1320×624`, **14,258 байт**. Он **пиксельно эквивалентен** PNG-атласу 41,807 байт (−65.9%). 128-атлас также поддержан и не включается в клиент одновременно с 256. PNG-версии служат fallback.
- Вокруг каждого элемента в атласе: 4px межплиточного защитного поля (edge extrusion). JSON-манифест содержит `assets[name].raster[256]`, anchors, iso grid neighbors, версии, SHA-256 и хешированные имена.
- Изображения не содержат строений, NPC, героя, ресурсов, берегов или мостов.

## Интеграция (локальный RC, без публикации)
В архиве находится `DL_TERRAIN_01/scripts/install_terrain.py`, который:
1. Проверяет формат текущего runtime и до изменений вычисляет SHA-256 утверждённых UI-иконок и файлов `data/`.
2. Копирует только новый отдельный каталог с 17 SVG и публичными атласами.
3. Добавляет защищённые статические routes `/assets/terrain/*.webp|*.png|manifest.json` c immutable-кэшированием хешированных атласов.
4. Подключает `/terrain-01.js` и заменяет **только** визуальную отрисовку процедурных landscape-клеток на подготовленные изометрические тайлы с fallback на старый renderer при неудачной загрузке.
5. Не изменяет `landscapePlace`, tool/item/game ID, `worldPoint`, NPC и сохранения.
6. Сверяет контрольные суммы всех защищённых файлов после инсталляции.

Запуск локально после распаковки:
```bash
python3 DL_TERRAIN_01/scripts/install_terrain.py ~/Downloads/dementor-live-test/projects/dementor-live/runtime
cd ~/Downloads/dementor-live-test/projects/dementor-live/runtime
npm start
```
В старых ветках с другой реализацией app.js установщик может **отказать** вместо неверной замены. Для реального релизного кандидата необходим full Node/browser/2-player acceptance и off-VM backup.
