# DL-TERRAIN-01 · игровая интеграция в RC3
**Дата:** 2026-10-20. **Статус:** draft PR / candidate, не production. База — ветка P5 CIVIC.

## От магазина до укладки
1. В магазине благоустройства все три товара показываются миниатюрами из **того же SVG-производного атласа**, что и земля. Покупка не меняет прежних условий: **10 плиток / 1 PAPER**.
2. Сразу после покупки количество хранится в прежнем `player.terrainBag.{paving,grass,flowers}`. В рюкзаке есть отдельный раздел «Покрытия». Это не древесина, не камень, не еда и не новые IDs предметов: совместимость старых балансов сохраняется.
3. Выбор материала в магазине или рюкзаке включает инструмент укладки. Нажатие на клетку **выбирает клетку**, не списывает товар. На карте отображается зелёный/красный ромб и строка причины отказа.
4. **«Применить»** отправляет прежнее `landscapePlace` только после выбора клетки. Сервер снова проверяет расстояние, препятствия, владельца, запас и занятость. Успех списывает **ровно одну** плитку. «Отмена» и `Esc` отключают инструмент.
5. На мобильном достаточно тапнуть клетку → «Применить»; drag-and-drop не используется.

## Земельные права (серверные, P0)
- Общая муниципальная земля, не перекрывающая ни один зарегистрированный частный участок: доступна всем жителям этого города, если нет препятствий.
- Приватный купленный участок: только `plot.owner===player.id`; чужие участки запрещены **до списания**.
- Непроданные зарезервированные участки защищены до покупки.
- Если покрытие пересекает границу не принадлежащего игроку участка, действие запрещено, включая границу по одной клетке.
- Дом/препятствие проверяется существующим `walkable`, а UI показывает предварительное предположение, не заменяющее серверную проверку.
- Старые уложенные покрытия не перезаписываются и не удаляются.

## Графика и архитектура
- **17/17** редактируемых изометрических SVG `assets-source/terrain/`: 3 дорожные, 3 газон, 3 цветы, 4 края, 4 угла.
- `tools/build-terrain.py` преобразует исходники в один WebP/PNG-атлас **на размер** 256×148 и 128×74. Во время Docker build получает хешированные имена и `public/assets/terrain/manifest.json`. Кэш immutable только для имен с SHA, манифест — no-cache. Старые иконки Paper Cut UI v2 нетронуты.
- `public/terrain-01.js`: детерминированный вариант по координатам; дорожные края/углы из соседних клеток; кэш геометрии по блокам **16×16**, ограничение отрисовки видимой областью, 4px gutters и 0,55 CSS px bleed для борьбы со швами.
- Все тайлы рисуются на уровне земли **до зданий, NPC и игроков**. Клиентская сетка кликов использует действующие ISO30 `screen/worldPoint`; коллизии и направление управления не меняются.
- `landscape.mjs`: производный `Map<x,y,tile>`, обновляемый при укладке. `landscapeSpeed` — O(1), больше не делает `tiles.some()` в каждом тике.
- `terrain-delta.mjs` + сервер SSE: первичная отправка полной карты, затем только новый отрезок `tiles[]` с `baseCount` и `city` (при смене города — полный снимок). На клиенте пустой diff повторно использует прежнюю коллекцию и chunk-кэш. Перезагрузка повторно получает полную карту. **Формат сериализованного `world.json` не меняется.**
