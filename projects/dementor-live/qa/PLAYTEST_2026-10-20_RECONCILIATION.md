## Новый будущий сюжет: камень, горные государства, туристические разрешения
Источник — 340–357, 388–413 и 396–409.
1. Местные каменные месторождения конечны; гарантировать достаточно ресурса для базовых зданий и развития стартового города.
2. Горный регион — источник обильного камня и дефицитного дерева. Нужна **транспортная логистика**, а не бесконечный склад рядом.
3. Пересечение границы по документам: туристический пропуск, отдельный сертификат экспорта камня с лимитом; PAPER за документы поступает мэрии.
4. NPC-пограничник с коротким объяснением требований. До ввода механик границу показывать закрытой, но сохранять визуальные знаки переходов.
5. Эти идеи **не** входят в RC текущего CIVIC P3: новая экономика и политика миграции камня требует независимых моделей. Не смешивать с уже работающими музеем и лесной тропой.
6. Университет и Валентина остаются без изменений.

## Релизные критерии
1. Все CI model/browser/persistence + Docker build PASS на одном exact SHA.
2. Read-only audit реального server `dementor-live-world` backup не уменьшает PAPER, не теряет owner/plot/chest/pager/материалы.
3. Не используется `--reset-world`. Доступен restore полного архива game volume + прежнего образа.
4. Старый и новый контейнеры не работают одновременно на одном томе.
5. Два тестировщика проходят первым делом: UI overflow, E на грядках/колодце, слои героя, торговлю, мосты, собственность, пейджер.
6. После cutover /api/health показывает **новую версию**; скачиваемый QA NDJSON только в изолированной сборке; реальный сервер не хранит QA по умолчанию.
7. До VM access/backup/approval никакой статус «DEPLOYED» не ставить.
