# Запись двух игроков: серверный QA-лог и видео
20 октября 2026 · `qa-recordings` — отдельные служебные файлы, без секретов.

**Проверочный запуск:** на тестовом Mac из `projects/dementor-live/runtime` с отдельным файлом состояния:

```bash
DEMENTOR_PORT=4183 \
DEMENTOR_STATE="$PWD/data/world-video-test.json" \
DEMENTOR_QA_LOG=1 \
npm start
```

Перед запуском убедитесь, что `world-video-test.json` — именно тестовый файл, а не сохранение опубликованного города. При новом запуске рядом создаётся каталог `data/qa-recordings/` и файл `session-<server UTC>-<uuid>.ndjson`; это **НЕ** файлы игры `world-video-test.json`. Не удалять игровые сохранения и никогда не применять `--reset-world`.

Для автоматических `node server.mjs --test` QA-журнал включён без дополнительной переменной.

**Видеозапись и аудио:** оба включают запись с микрофоном на своих устройствах. В начале оба по очереди нажимают «● Метка видео»; произносят вслух `VIDEO-001` и `VIDEO-002`. Сервер хранит UTC-время и `offsetMs` от запуска. Далее ставить метку перед важным сценарием или багом, записывать его ID. Не вставлять личные данные в тестовые сообщения или письма.

**Формат события:**

```json
{"seq":3,"sessionId":"...","wallTime":"2026-10-20T10:00:00.000Z","offsetMs":4234,"type":"game_action","playerId":"...","playerName":"Тестер","cityId":"origin","scene":"city","x":10,"y":12,"action":"pagerSend","target":"phone-square","requestId":"...","ok":true,"walletBefore":5,"walletAfter":4,"deltaPaper":-1,"errorCode":null}
```

Остальные события: `recording_started`, `player_join`, `player_connect`, `player_disconnect`, `movement_sample`, `player_state`, `game_action`, `video_marker`, `recording_stopped`. Это событийная выборка, а не запись каждого кадра. Тексты чата, письма мэру и пейджера, токены доступа и raw body запросов намеренно исключены.

В автоматической `--test` сборке кнопка «⇩ QA-лог» выдаёт отдельный NDJSON через защищённый авторизацией endpoint. В обычной сборке скачивание через UI отключено — берите файл локально на сервере. При штатной работе логирование выключено, включается только осознанно через `DEMENTOR_QA_LOG=1`.

**После теста:** сохраните обе видеозаписи, аудио, последний NDJSON, commit SHA/название сборки, краткий итог и заполненный `PLAYTEST_CHECKLIST_v2`. Сверяйте метки `video_marker` с произнесёнными маркерами и начинайте анализ с P0 (невозможность движения, утрата PAPER/ресурсов, задвоение, сломанный вход/сохранения).
