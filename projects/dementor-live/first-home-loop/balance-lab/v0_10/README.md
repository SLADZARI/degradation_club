# DEMENTOR LIVE — WORLD ORGANISM v0.10 UNIFIED ATLAS
**20 октября 2026 · LAB IMPLEMENTED / NOT SERVER / NOT MASTER GDD**

Собраны все подтверждённо доступные автономные HTML версии **v0.2, v0.3, v0.4, v0.5, v0.6, v0.7 RC2, v0.7.1 P0 и v0.8**. В GitHub отдельно найдены экспериментальные [v0.9 (PR #273)](https://github.com/SLADZARI/degradation_club/pull/273) и [v0.9.1 (PR #274)](https://github.com/SLADZARI/degradation_club/pull/274); их Node QA-происхождение изучено, но исходники **не вставлены побайтово** в прежний браузерный движок. Собран *новый адаптер*, сохраняющий исполняемое экономическое ядро v0.8.

Объединённая автономная модель содержит **13 паспортов регионов/сцен, 48 типов сущностей, 10 тегов ролей** и старый SVG граф из 42 узлов с закреплённой панелью денежных и материальных показателей. Две архитектурные ветви CIVIC и UNIVERSE остаются различимы, мировые документы и черновые PR — не доказательство deployment.

### Реально работают в одном автономном HTML
Экономика v0.8 (физические запасы, PAPER/escrow, finite city orders, продукты, HEMP→PAPER_SHEET, P2P, огороды, собственные участки) + новые транзакционные лабораторные демонстрации: ограниченно оплаченная NPC работа и курьерская поставка с реальным cargo ledger; покупка туристической карты и графовый маршрут с добровольной однократной встречей; конечные большие залежи камня с уменьшаемым stock/size. Город за 5000 USD в «Обители Габеля» только документирован и НЕ исполняет внешнюю платёжную операцию; имена шести областей не выдуманы.

### QA
**55/55 локальных Node тестов PASS**, включая 36 stress: 3/4/5 агентов × normal/forest/dry/treasury × 1/7/30 суток, **52/52 инварианта**. Chromium 1440/390/320px: 42 legacy узла и 13 новых территорий, фиксированная верхняя панель, 3 демонстрации, импорт v0.10 D30 JSON, без JS ошибок. D30 3-agents normal: 3600 PAPER (город 2301), 3 проекта, 3 дома, 6/6 PAPER_SHEET использовано, 36 HEMP переработано, 90 CARROT съедено. В v0.10 добавлено +35 initial STONE из трёх тестовых узлов — это не строго неизменённый полный баланс v0.8.

**Блокер:** replay ручных atlas-действий по журналу НЕ сертифицирован (самостоятельные проверки возвращают NOT_VERIFIED); графовые маршруты не равны реальным серверным путям, NPC опыт/мультиплеер и PvE в production не проверены. Внешние CI v0.9/v0.9.1 ранее reported PASS отдельно; мы их не перезапускали.
