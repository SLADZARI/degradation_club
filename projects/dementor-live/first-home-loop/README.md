## 1. Первую страницу прочитать за 90 секунд

**Город (общая сцена):** персонаж появляется у палатки мэрии, получает бесплатный изнашиваемый инструмент. Первый городской проект — **площадь**, НЕ бумажная фабрика. Берёт конкретное финансируемое поручение → идёт за ресурсом → добывает → физически переносит ограниченный груз → сдаёт и получает PAPER за принятый результат → видит изменение этапа строительства.

**Своя земля (отдельная сцена участка):** на заработанное покупает участок. Он НЕ чистый, а заросший: деревья, кусты, трава, камни, дикорастущая пища и семена. Войдя на участок, игрок видит новую подробную сетку; расчищает место, получает конечную древесину/камень/семена, строит **простую палатку**.

**Интерьер (третья сцена):** входит внутрь построенной палатки. Несколько клеток, первый **сундук** и **кровать**. Личный инвентарь, расположение и права не дублируются между сценами.

**Мини-огород:** рядом с палаткой расчищает грядки → готовит почву → сеет **HEMP** для будущей бумаги и/или **морковь/тыкву/арбуз** для еды → поливает → ждёт рост по реальному времени → собирает урожай. Первые семена можно найти при расчистке, купить или обменять; семена позднее воспроизводятся из растений по видам. Конопля — сырьё, **не** напрямую PAPER.

**Другие жители:** игроки могут встречаться, дарить, **обменивать** дерево/камень/семена, **продавать** за PAPER, приглашать на участок, выдавать отдельные разрешения поливать, собирать для владельца либо **брать себе** определённый урожай, помогать по оплачиваемым поручениям. При успешном несанкционированном сборе зрелого овоща с доступного чужого огорода предмет переходит игроку и **сразу** появляется запись на отдельной городской **Доске воров**. Вход на закрытый участок и доступ в чужой сундук от этого не разрешаются.

**Возвращение в город:** игрок с урожаем/ресурсами/опытом приходит к новым работам, сделкам и знакомым. Результаты остаются на общей карте. Здесь цикл замыкается без обязательной фабрики.

### Переходы
`CITY → CITY_PROJECT_WORK → PURCHASE_PLOT → ENTER_PLOT → CLEAR/FOREAGE → PITCH_TENT → ENTER_INTERIOR → CHEST/BED → RETURN_TO_PLOT → PREPARE_BEDS → SOW/WATER/GROW/HARVEST → P2P_TRADE / ALLOWED_PICKUP / THEFT_BOARD → CITY`.

## 4. Как тестируем 3 игроков (первый большой loop)
Шмыгель: работает в городе, покупает лесистую землю, очищает её, строит палатку, сеет hemp и морковь.
Бусел: покупает участок с иным соотношением древесины/камня, меняет/покупает нужное у Шмыгеля, разрешает взять часть моркови.
Фырка: зарабатывает рабочими поручениями, приходит помогать за обеспеченную оплату; при снятии неразрешённой моркови с доступной чужой грядки появляется на Доске воров.
Тестируются ownership и лимиты участка; площадь, доступ, источник WOOD/STONE/SEED, ONE-COMMIT обмен товара/PAPER, различные permissions; разница между HELP_GARDEN, HARVEST_FOR_OWNER, TAKE_HARVEST и THEFT_COMMITTED; длительность роста по REAL_TIME; отсутствие дублирования и сохранение рестарта.

## 5. Открытые вопросы и НЕ утвердившиеся числа
- Размер участка и сетки (старый 12×12 только TEST), размещение растительности и различия соседних участков.
- Цена земли, схема финансирования города, заработок за поручения, время до первого дома.
- Материалы палатки, происхождение тента, стоимость/длительность; сон и сундук.
- Вероятности находки семян, объёмы дерева и камня, способ добычи, износ инструмента.
- Сколько поливать, время роста, площадь моркови/тыквы/арбуза и конопли, правила воспроизводства семян, первая дикорастущая еда.
- Хранение и срок годности продуктов, в том числе на улице/в сундуке; холодильник только позднее.
- По каким режимам гости заходят на участок; точный UI разрешений, срок нахождения вора на доске, реакции мира.
- Точная дистанция прямых сделок и лимиты грузоподъёмности.
- Исторический конфликт SURVIVAL: поздний основной CORE задаёт голод **только при активной игре**, замедление и духа с доступной едой, хотя старый Master GDD v0.1 описывал отсутствие обязательного голода. Для первого цикла руководствоваться позднейшим CORE.
Никакие числовые балансы из World Organism v0.5 не считать утверждёнными для live игры.

## Следующий масштаб мира — города игроков и лесные экспедиции (обсуждение 18.10.2026)

**Не заменяет FIRST HOME LOOP.** Первый игрок начинает с временной мэрии, площади, заросшего личного участка, палатки и огорода. После личного прогресса [В] он сможет претендовать на предлагаемую площадку **собственного города** и отдельный режим мэра, а за пределами стартовых районов [В] возможны лесные маршруты, туман исследования и разные PvE/небоевые встречи. Подробности [городской собственности и экономики](../design/CITY_OWNERSHIP_REGIONS_RESEARCH_v0.1_CANDIDATE.md), [дикого мира и событий](../design/WILDERNESS_FOG_ENCOUNTERS_v0.1_CANDIDATE.md), [проверка совместимости 27 доменов](../design/CROSSCHECK_CITY_WILDERNESS_27_v0.1.md) и [дословное сообщение пользователя](../design/conversations/USER_VOICE_2026-10-18_VERBATIM.md). Остаются открытыми баланс, бюджет мэра, механики ботов и боёв, источник уникальных вещей. Новая возможность **не** реализована в ранее описанном локальном прототипе.
