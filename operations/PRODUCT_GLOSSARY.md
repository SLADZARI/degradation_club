# Dementor Club — Product Glossary

Статус: approved working canon
Дата фиксации: 2026-08-25
Источник: рабочий разговор команды Dementor Club 25.08.2026

Этот словарь фиксирует границы продуктовых сущностей клуба. Не смешивать определения при проектировании сайта, контента, аналитики и backend.

## Merch

Физические товары и артефакты Dementor Club.

MVP-механика: каталог/карточка товара → `Предзаказ` → контакт пользователя → заявка попадает команде.

На первом этапе полноценный e-commerce, склад, автоматическое списание денег и сложный checkout не обязательны.

## Event / Событие

Любой офлайн-формат Dementor Club: встреча, выезд, физический интенсив, совместная активность, курс с обязательным физическим присутствием и т.п.

Ключевой критерий: участие происходит офлайн.

Event может иметь образовательную программу, но в продуктовой архитектуре остаётся `event`, а не `course`.

Минимальные поля: статус, название, концепция, дементор/ведущий, город/место если определено, дата если определена, описание, визуал, следующий шаг пользователя.

## Course / Курс

Онлайн-продукт, который пользователь проходит дистанционно.

Ключевой критерий: основной пользовательский путь происходит онлайн.

Для первого MVP курс может быть многодневным/длительным: пользователь получает ограниченный набор вопросов/заданий на день, отправляет ответы и затем получает результат/следующий шаг по e-mail.

Незавершённые дневные вопросы не исчезают и остаются до ответа.

AI используется точечно — прежде всего для анализа входных ответов или подготовки результата. Не строить продукт вокруг постоянного AI-чата без отдельного решения.

## Join / Вступление в Dementor Club

Отдельный onboarding/анкета для знакомства пользователя с клубом и формирования профиля по 9 каноническим сферам.

MVP: пользователь проходит onboarding → оставляет e-mail → получает результат по e-mail → результаты сохраняются с привязкой к e-mail.

Позже e-mail может стать ключом для полноценного аккаунта без потери накопленных результатов.

## Member / User identity

На первом MVP полноценный аккаунт не обязателен.

Минимальная идентичность пользователя: e-mail.

Все новые пользовательские данные, которые имеет смысл использовать после появления авторизации, должны проектироваться так, чтобы их можно было привязать к e-mail и затем мигрировать в полноценный user account.

## Preorder / Предзаказ

Основная первая коммерческая механика merch.

Это не имитация реального списания денег. Интерфейс может играть с эстетикой «покупки», но пользователь должен понимать фактическое действие: он оформляет предзаказ/заявку, а не совершает завершённую оплату, если платежа реально нет.

Минимальный результат: товар + параметры заказа + контакт пользователя + timestamp доступны команде.

## Donation / Донат

Добровольная финансовая поддержка развития клуба. Отдельная публичная страница/блок.

Тон: фирменный чёрный юмор Dementor Club. Рабочая смысловая рамка — борьба с «финансовой беззаботицей» и донат как один из способов её лечения/усугубления. Финальный copy требует отдельного утверждения.

## Dementor

Ведущий/автор/персона клуба, связанный с конкретными программами, курсами, событиями, проектами и сферами. Профиль дементора должен показывать не только биографию, но и доступные/связанные продукты и активности.

## Project

Самостоятельный продукт или медиа внутри экосистемы Dementor Club. Проект сохраняет собственную редакционную и продуктовую логику. Первый отдельный проект — «Логика и осознанность».

## Важное разделение

- `Merch` = физический товар.
- `Event` = офлайн.
- `Course` = онлайн.
- `Join` = вход/профилирование участника, не курс и не событие.
- `Donation` = поддержка клуба, не покупка товара и не членский взнос, пока отдельная механика членства не утверждена.

Любая новая сущность сначала классифицируется по этому словарю и канонической taxonomy клуба, затем передаётся на сайт.
