# DC-9 Personal State Copy Matrix v0.1

Status: **DRAFT / EDITORIAL QA REQUIRED / NOT PRODUCTION**  
Date: 2026-09-01

This document defines the first complete authoring matrix for the **personal state fixation** layer of DC-9 results.

Authority:
- `operations/DC9_RESULT_SYSTEM_V0.1.md` — factual result model and final `0–5` sphere level;
- `operations/CONTENT_TAXONOMY_AND_DEMENTOR_LEVELS.md` — canonical nine spheres and level taxonomy;
- `operations/DC9_RESULT_LANGUAGE_STANDARD_V0.1.md` — public result-language contract.

This matrix does **not** change scoring, guards, sphere semantics, result prominence or Community routing.

The `0–5` value below is an internal authoring key and factual sphere level. It is not a moral rank and must not be rewritten as “better / worse”.

Canonical level names:

- `0` — Не затронут
- `1` — Первичные признаки
- `2` — Осознанная деградация
- `3` — Устойчивая форма
- `4` — Тяжёлое дементорство
- `5` — Дементор

Permanent territory descriptor:

> **ВЕРСИЯ СЕБЯ, КОТОРУЮ УЖЕ ВСЕ ЗАПОМНИЛИ.**

**ОБРАЗ УДЕРЖИВАЕТСЯ ВРУЧНУЮ.**  
Неловкости по возможности объясняются до восстановления исходной версии событий.

### 1 / ПЕРВИЧНЫЕ ПРИЗНАКИ

Репутация уже иногда переживает мелкие повреждения без отдельного совещания.  
Крупные случаи пока сопровождаются ремонтом.

### 2 / ОСОЗНАННАЯ ДЕГРАДАЦИЯ

Старые роли ещё включаются автоматически, но уже не на каждый вызов.  
Несовершенство допускается, если не мешает основным функциям.

### 3 / УСТОЙЧИВАЯ ФОРМА

Ожидания окружающих перестали быть обязательной инструкцией.  
Образ всё ещё учитывается, но решения уже принимаются не только ради него.

### 4 / ТЯЖЁЛОЕ ДЕМЕНТОРСТВО

Старая удобная версия себя вызывается всё реже.  
Неловкость, границы и несовершенство выдерживаются без срочного восстановления репутации.

### 5 / ДЕМЕНТОР

**РЕПУТАЦИЯ ПЕРЕВЕДЕНА В РЕЖИМ СОПРОВОЖДЕНИЯ.**

Новизна и статус всё ещё успешно проходят закупочную комиссию.

### 1 / ПЕРВИЧНЫЕ ПРИЗНАКИ

Импульсная покупка уже иногда получает вопрос «зачем».

Статус перестаёт быть самостоятельной функцией.

### 4 / ТЯЖЁЛОЕ ДЕМЕНТОРСТВО

Прошлые деньги больше не продлевают срок хранения вещи автоматически.

### 5 / ДЕМЕНТОР

# Matrix-level editorial QA

Before promotion to approved result copy, review all 54 states as one bank.

Required checks:

1. No state says the user is a type of person.
2. No state turns `0–5` into good/bad ranking.
3. Progression `0 → 5` remains semantically aligned with the canonical sphere.
4. High state is not merely adult competence; it must reflect the sphere's Dementor direction while responsibility is already protected by scoring guards.
5. No advice / recommendation language.
6. Permanent territory descriptor is not repeated as the personal state line.
7. Institutional deadpan stays secondary to clarity.
8. Strong absurdity remains rare across the full 54-state bank.
9. No repeated universal template such as `НЕ ОБНАРУЖЕНО / РАЗРЕШЕНО` across spheres.
10. Copy remains understandable to a person who never saw the questionnaire internals.
