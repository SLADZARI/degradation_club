# DC-9 Personal State Copy Matrix v0.2

Status: **DRAFT / EDITORIAL QA REQUIRED / NOT PRODUCTION**  
Date: 2026-09-01

This document defines the authoring matrix for the **personal state fixation** layer of DC-9 results.

Authority:
- `operations/DC9_RESULT_SYSTEM_V0.1.md` — factual result model and final `0–5` sphere level;
- `operations/CONTENT_TAXONOMY_AND_DEMENTOR_LEVELS.md` — canonical nine spheres and level taxonomy;
- `operations/DC9_RESULT_LANGUAGE_STANDARD_V0.1.md` — public result-language contract.

This matrix does **not** change scoring, guards, sphere semantics, result prominence or Community routing.

The `0–5` value below is an internal authoring key and factual sphere level. It is not a moral rank and must not be rewritten as “better / worse”.

Canonical level names:

- `0` — Не затронут
- `1` — Первичные признаки
- `2` — Осознанная деградация
- `3` — Устойчивая форма
- `4` — Тяжёлое дементорство
- `5` — Дементор

## Score-targeting rule

Every line must make sense for **that exact factual level**, not merely for the sphere in general.

Internal arc:
- `0` — the conventional mechanism is basically intact and still runs the show;
- `1` — the first crack has appeared, but the old reflex still usually wins;
- `2` — the user deliberately experiments with doing less / releasing the old mechanism;
- `3` — the new behaviour is stable in ordinary situations, but not yet universal;
- `4` — the behaviour survives pressure and inconvenience; responsibility remains intact;
- `5` — the behaviour is robust and no longer needs to be performed as an ideology or achievement.

Editorial check for every state:

> Could this exact line plausibly belong to the level above or below without changing anything?

If yes, the state is too generic and must be rewritten.

Humor check:
- every state should contain at least one recognisable contradiction, dry observation or satirical turn;
- strong punchline grammar is not mandatory on every card;
- the progression `0 → 5` must remain clearer than the joke.

## 01 / ЛИЧНОСТЬ

Permanent territory descriptor:

> **ВЕРСИЯ СЕБЯ, КОТОРУЮ УЖЕ ВСЕ ЗАПОМНИЛИ.**

### 0 / НЕ ЗАТРОНУТ

**ОБРАЗ УДЕРЖИВАЕТСЯ ВРУЧНУЮ.**  
Если случилась неловкость, первым делом восстанавливается правильная версия событий.

### 1 / ПЕРВИЧНЫЕ ПРИЗНАКИ

Репутация уже иногда переживает мелкие повреждения без ремонта.  
На серьёзные случаи набор оправданий пока выезжает полностью.

### 2 / ОСОЗНАННАЯ ДЕГРАДАЦИЯ

Не каждую старую роль приходится доигрывать до титров.  
Иногда можно разочаровать чужое ожидание и не созывать пресс-конференцию.

### 3 / УСТОЙЧИВАЯ ФОРМА

Ожидания окружающих переведены из инструкции в справочный материал.  
Неловкость уже не всегда считается чрезвычайной ситуацией.

### 4 / ТЯЖЁЛОЕ ДЕМЕНТОРСТВО

Старая удобная версия себя вызывается только по действительно важным поводам.  
На обычное чужое недовольство выездная бригада больше не отправляется.

### 5 / ДЕМЕНТОР

**РЕПУТАЦИЯ ОСТАВЛЕНА НА ЕСТЕСТВЕННОЙ ТЯГЕ.**  
Реальные решения обычно обслуживаются раньше впечатления от них.

## 02 / РАБОТА

Permanent territory descriptor:

> **МЕСТО, ГДЕ ПУСТОЙ КАЛЕНДАРЬ ТРЕБУЕТ ОБЪЯСНЕНИЙ.**

### 0 / НЕ ЗАТРОНУТ

Работа продолжается, пока остаётся рабочее время.  
Если задача закончилась раньше — находится другая. Порядок должен быть соблюдён.

### 1 / ПЕРВИЧНЫЕ ПРИЗНАКИ

Лишняя работа уже замечается, но пустое окно в календаре всё ещё выглядит как улика.

### 2 / ОСОЗНАННАЯ ДЕГРАДАЦИЯ

Результат начал конкурировать с занятостью за право называться работой.

### 3 / УСТОЙЧИВАЯ ФОРМА

Часть занятости снята с производства.  
Второй ночной подвиг подряд уже вызывает вопрос не о героях, а о плане.

### 4 / ТЯЖЁЛОЕ ДЕМЕНТОРСТВО

Закрытая задача больше не обязана немедленно рожать новую.  
Повторяющиеся пожары сначала проверяются на наличие архитектора пожаров.

### 5 / ДЕМЕНТОР

**РАБОТА ИНОГДА ЗАКАНЧИВАЕТСЯ РАНЬШЕ РАБОЧЕГО ДНЯ.**

## 03 / ПОТРЕБЛЕНИЕ

Permanent territory descriptor:

> **ВЕЩИ. ЧАСТЬ ИЗ НИХ УЖЕ У ВАС ЕСТЬ.**

### 0 / НЕ ЗАТРОНУТ

Новизна и скидка по-прежнему проходят закупочную комиссию без очереди.  
Прошлая цена вещи считается уважительной причиной хранить её дальше.

### 1 / ПЕРВИЧНЫЕ ПРИЗНАКИ

Перед покупкой уже иногда появляется вопрос «зачем».  
Скидка пока отвечает первой.

### 2 / ОСОЗНАННАЯ ДЕГРАДАЦИЯ

Не каждая корзина доживает до оплаты.  
Некоторые вещи впервые получают ночь на размышление вместе с владельцем.

### 3 / УСТОЙЧИВАЯ ФОРМА

Вещам всё чаще приходится быть полезными и после момента покупки.  
Статус признан функцией, но не основной.

### 4 / ТЯЖЁЛОЕ ДЕМЕНТОРСТВО

Прошлые деньги больше не продлевают срок хранения автоматически.  
Если вещь год не нужна, её высокая цена уже не считается формой занятости шкафа.

### 5 / ДЕМЕНТОР

Реклама по-прежнему показывает много вещей. В дом попадает заметно меньше.  
Отказ от покупки отдельно не празднуется: покупать тоже можно.

# v0.2 editorial QA checklist

For all `54/54` states verify:

1. The exact `0–5` state is readable from behaviour, not only from the canonical level label.
2. Adjacent states are meaningfully different:
   - `0 ≠ 1` — first crack exists only at `1`;
   - `1 ≠ 2` — deliberate choice appears at `2`;
   - `2 ≠ 3` — stability appears at `3`;
   - `3 ≠ 4` — behaviour survives pressure at `4`;
   - `4 ≠ 5` — at `5` the behaviour no longer needs performance, ideology or constant self-monitoring.
3. Every state contains a recognisable contradiction, dry observation or satirical turn.
4. No line diagnoses personality, health or defectiveness.
5. No state tells the user what they should do.
6. High level does not mean irresponsibility: guard semantics remain visible in the copy where relevant.
7. No universal repeated template such as `X НЕ ОБНАРУЖЕНО / Y РАЗРЕШЕНО` is used across all spheres.
8. Strong absurdity remains sparse enough that lines like `СМЫСЛ НЕ ОБНАРУЖЕН. ЭКСПЛУАТАЦИЯ РАЗРЕШЕНА.` still land.
