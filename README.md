# Dementor Club

Ветка клуба: концепция, позиционирование, правила, продукты, контент, мероприятия и операционные материалы.

## Что хранится здесь

- `concept/` — идея клуба, аудитория, ценность, принципы;
- `brand/` — язык, айдентика, правила коммуникации;
- `programs/` — форматы клуба, активности, продукты;
- `content/` — клубный контент и редакционный календарь;
- `operations/` — процессы, роли, чек-листы, партнёры;
- `research/` — исследования и референсы;
- `DRIVE.md` — связь с Google Drive.

## Граница ответственности

Эта ветка не содержит код официального сайта. Сайт развивается отдельно в `dementor-club-site`. Канал «Логика и осознанность» развивается отдельно в `logic-awareness`.

Материалы, которые сайт использует из клуба, должны попадать сюда как утверждённый source-of-truth, а в ветку сайта — уже как реализованный контент или код.
