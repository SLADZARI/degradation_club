# Dementor Club — Merch / Objects

Этот каталог — канонический source-of-truth для физических товаров Dementor Club.

## Назначение

Здесь хранятся:

- карточки товаров;
- серии и drops;
- материалы, размеры и варианты;
- базовые цены;
- правила валют;
- статусы разработки и производства;
- ограничения по тиражам;
- упаковка и маркировка;
- связи товаров с событиями и проектами клуба.

Сайт не является источником правды для товаров: он только реализует утверждённые данные из этого каталога.

## Каноническая товарная архитектура

Публичный раздел сайта может называться `Merch`, но внутренняя продуктовая система называется **Dementor Objects**.

Категории:

1. `Objects` — физические концептуальные объекты.
2. `Wear` — одежда и носимые предметы.
3. `Paper` — печатные и бумажные объекты.
4. `Editions` — номерные и ограниченные серии.
5. `Project Editions` — товары самостоятельных проектов клуба.

Отдельная премиальная линия:

# EXPENSIVE THINGS WITHOUT MEANING
## ДОРОГИЕ ВЕЩИ БЕЗ СМЫСЛА

Это не сувенирная линия. Объект должен существовать как самостоятельная физическая вещь, быть хорошо изготовлен и сохранять ценность даже без знания контекста Dementor Club.

Первые канонические объекты линии:

- `OBJECT 001 — НЕ НАДО`;
- `OBJECT 002 — ЦЕЛЬ`.

## Валюта

Каноническая базовая валюта всех товаров — **EUR**.

Правила:

- `base_price_eur` хранится как источник правды;
- на сайте пользователь может переключать отображение валюты;
- PLN, USD, GBP и другие валюты являются только отображением;
- конвертация выполняется по актуальному курсу;
- после конвертации цена округляется по правилам интерфейса;
- валютная конвертация не меняет каноническую цену товара в EUR;
- для лимитированных объектов допускается ручная региональная цена только как отдельное утверждённое исключение.

## Принцип ценообразования

Dementor Club не строит цены от минимально возможной себестоимости. Для планирования используется верхняя реалистичная граница себестоимости малой серии: качественный материал, малый тираж, локальное производство, прототипирование, упаковка, брак и логистика.

Для линии `ДОРОГИЕ ВЕЩИ БЕЗ СМЫСЛА` цена не обязана быть линейной функцией себестоимости или массы.

В частности для `ЦЕЛИ` действует специальное правило:

> увеличение размера повышает цену сверхлинейно: крупная ЦЕЛЬ должна стоить дороже пропорционального увеличения её массы относительно маленькой ЦЕЛИ.

Причины внутри продуктовой логики: масштаб, сложность производства и доставки, редкость, визуальный эффект, ограниченность и намеренная абсурдность большого объекта.

## Статусы товара

`idea / prototype / approved / production / available / sold-out / archived / cancelled`

Ни один объект со статусом `idea` или `prototype` не должен подаваться на сайте как доступный к покупке.

## WIP entity architecture — 2026-08-25

В ветке `wip-merch-source-entities` проектируется расширенная модель магазина:

`COLLECTION / DROP → ARTWORK + BASE SPEC → PRODUCT → VARIANT / SKU → OFFER → ASSET`

См. `merch/MERCH_ENTITY_MODEL.md`.

Это разделяет:

- графический statement / artwork;
- переиспользуемую физическую спецификацию tee/hoodie;
- конкретный товар (artwork + base spec);
- конкретный размер/цвет SKU;
- состояние продажи и checkout;
- изображения и другие assets.
