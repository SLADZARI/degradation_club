## Cross-system issues

### 1. Static score ladder

Current question arrays are stored score `0,1,2,3` in display order. Without shuffle this leaks the mechanic and makes the test gameable.

Required: shuffle answer display order independently on every question while preserving score binding.

### 2. Hidden mechanics are visible

Current public quiz exposes sphere tags and guard-type wording. Canon says tag and psychometric mechanics are internal.

Required: hide tag/score/guard metadata from public UI.

### 3. Forbidden public wording appears

Examples include formulations equivalent to:

- “Министерство проверяет способность…”;
- “Что важнее…”;
- “Почему вы…”;
- “контроль качества деградации”.

These conflict with current scenario rules.

### 4. Guards are self-report

Many intent guards ask the user to explain why they act in a particular way. The most enlightened answer is obvious.

Required: replace motivation declarations with behavior under temptation, cost or consequence.

### 5. Score 3 often means competence

Recurring false positives for maximum Dementor meaning:

- good delegation;
- healthy boundaries;
- risk management;
- fact checking;
- source verification;
- efficient automation;
- balanced self-development.

These are useful `2` behaviors but cannot automatically define `3`.

### 6. Current equal-weight assumption

Production has one thematic question per tag, so question count and tag count are structurally fixed. The new lab will test variable evidence counts and seven impact bands without changing canonical production scoring until approved.

## Approval test for every score 3

Ask:

> Does this answer show that the relevant successful-success construction has lost power over the decision, or does it merely make the person smarter, calmer, healthier or more competent?

If the second description is sufficient, the answer should normally be score `2`, and the scene/score-3 option needs redesign.
