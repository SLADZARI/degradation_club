160 / LLM BUILD CONTRACT

LLM не выбирает дизайн из воздуха. Она заполняет contract.

entity_type: event | course | dementor | project | merch
entity_id: exact source id
presentation_role: link | micro | inline | row | relation | feature | hero | detail | preview
context: home | index | entity-detail | related | activity | test | article
status: exact factual state
primary_action: source-approved action only
metadata: render only populated / approved fields
quote: requires explicit source + author
viewport_contract: web + tablet + mobile
empty_state: explicit, never fabricate entities
interaction_states: default / hover / focus / selected / disabled / processing
visual_subsystem: club | project-local
ink_level: 0..3 by page contract
motion: only approved behaviours

Entity определяет содержание. Presentation role определяет форму. Context определяет плотность. Responsive contract определяет перестройку. LLM не проектирует эти четыре вещи заново.
