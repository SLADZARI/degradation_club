## Implementation
The existing `workspace/workspace-shell-v1.js` already owns the canonical navigation, identity, logout and role gating. No parallel JS menu was added.

The implementation modifies only `workspace/workspace.css`:
- removes the desktop 240px left-column presentation by switching `.dcw-app` to one column;
- reuses the existing `.dcw-sidebar` shell host as a sticky top shellbar rather than creating a second host;
- desktop layout becomes `brand → canonical nav → identity/logout`;
- existing role-aware links remain generated by the same Workspace Shell runtime;
- the old informational boundary block is hidden in top-nav presentation;
- top content offsets follow the shell height;
- <=900px uses the same compact single navigation owner;
- <=620px uses two visual rows (`brand + identity`, then the same nav), not a second mobile menu implementation.
