# Dementor Club — Visual Reference Board v1.0

Status: canonical reference map for the official site.

## Responsibility map

- Public Records — architecture and ecosystem logic.
- Actual Source — catalog, indexes, metadata, dense listings.
- 032c — editorial aggression, headline-thinking, magazine hierarchy.
- Mouthwash — composition, scale, rhythm, whitespace, storytelling.
- DIA — motion, kinetic typography, behavior systems.
- Dementor Ink — proprietary visual disruption.

Rule: never copy a reference wholesale. Every reference is tagged by TAKE / DON'T TAKE / USE IN.

## A. Public Records — Architecture

### 01 Homepage / ecosystem switchboard
Source: https://publicrecords.nyc/
TAKE: home as live ecosystem hub; current events precede static institutional copy; multiple activities coexist under one interface.
DON'T TAKE: music-club aesthetic itself.
USE IN: Home, Events, Current activity.

### 02 Event calendar
Source: https://publicrecords.nyc/
TAKE: event as an entity with type/date/time/venue/CTA; dense list without SaaS cards; quick classification.
DON'T TAKE: literal Club/Live/Etc taxonomy.
USE IN: Events index and homepage current block.

### 03 Multi-space ecosystem
Source: https://publicrecords.nyc/
TAKE: sub-spaces preserve distinct character while staying inside a common brand system.
DON'T TAKE: physical venue model one-to-one.
USE IN: Projects / Community / Merch / Events.

### 04 Public Records Website case
Source: https://sometimes-always.com/projects/public-records-website/
TAKE: typography-led structure able to host very different content; simple flow that gives content priority.
DON'T TAKE: pure studio minimalism.
USE IN: global IA and templates.

### 05 Poster communication system
Source: https://sometimes-always.com/projects/public-records-posters/
TAKE: one system generates many event outputs without turning every event into a new brand.
DON'T TAKE: literal Müller-Brockmann/Fugazi styling.
USE IN: event posters, social derivatives, event cards.

## B. Actual Source — Catalog

### 06 Home
Source: https://actualsource.org/
TAKE: heterogeneous objects feel like one culture; catalog has priority over marketing copy.
DON'T TAKE: e-commerce as the club's core mental model.
USE IN: Projects, Merch, Archive.

### 07 Collections
Source: https://actualsource.org/collections
TAKE: dense repeatable listing, filters, category logic.
DON'T TAKE: store terminology where there is no purchase.
USE IN: archive, merch, community directory.

### 08 Books
Source: https://actualsource.org/collections/books
TAKE: high density + concise metadata + calm hierarchy.
DON'T TAKE: conventional product grid literally.
USE IN: resources, publications, project indexes.

### 09 Catalog
Source: https://actualsource.org/collections/catalog
TAKE: publisher/brand/type/status/price metadata as visual material.
DON'T TAKE: turning every object into a SKU.
USE IN: filters, statuses, metadata system.

### 10 Product detail
Source: https://actualsource.org/products/ok-rm-a-meaningful-order
TAKE: object first, marketing second; image and facts dominate.
DON'T TAKE: commerce UX when not needed.

## C. 032c — Editorial aggression

### 11 Homepage
Source: https://www.032c.com/
TAKE: headline as primary visual object; culture/editorial/commerce can coexist.
DON'T TAKE: red brand code or fashion voice.
USE IN: homepage statements, editorial feed.

### 12 Magazine index
Source: https://magazine.032c.com/
TAKE: issue/category/newness as navigation; publication as a system rather than a card feed.
DON'T TAKE: magazine styling as decoration.
USE IN: archive and recaps.

### 13 Mirko Borsche / 2026 redesign
Source: https://magazine.032c.com/magazine/brenda-s-business-with-mirko-borsche
TAKE: strict grid, long headlines, generous line spacing, orientation markers, repeated elements, brand-book discipline.
DON'T TAKE: rigidity as an end in itself.
USE IN: typography rules, longreads, page orientation.

### 14 Store front page
Source: https://www.032c.com/pages/store-frontpage
TAKE: merch remains part of editorial culture rather than a detached shop.
DON'T TAKE: luxury/fashion merchandising conventions.
USE IN: Merch.

### 15 Richard Turley / robust editorial structure
Source: https://magazine.032c.com/magazine/richard-turley-a-lazy-modernist-in-corporate-america
TAKE: strong templates free energy for ideas; support three reading depths: headline / caption / full text.
DON'T TAKE: visual noise for its own sake.
USE IN: editorial system and scanning behavior.

## D. Mouthwash — Composition

### 16 Home
Source: https://mouthwash.studio/
TAKE: generous whitespace, strong scale contrast, few objects per viewport.
DON'T TAKE: polished agency-luxury finish.
USE IN: homepage rhythm.

### 17 Work index
Source: https://mouthwash.studio/work/
TAKE: titles + disciplines + categories as navigation; project does not need decorative cards.
DON'T TAKE: agency portfolio semantics.
USE IN: projects index and archive.

### 18 Mesura
Source: https://mouthwash.studio/project/mesura/
TAKE: non-linear discovery; Projects/Objects/Resources/Editorial connect into a content graph.
DON'T TAKE: premium architecture tone.
USE IN: related-content engine and project pages.

### 19 T1 Energy
Source: https://mouthwash.studio/project/t1-energy/
TAKE: tension in type/form resolved through motion; explain complexity visually; detail without density.
DON'T TAKE: tech-energy visual language.
USE IN: type interactions and explanatory sections.

### 20 Seed
Source: https://mouthwash.studio/project/seed/
TAKE: behavior-based framework instead of random animations; one system behaves differently by context.
DON'T TAKE: science/organic visual code.
USE IN: naming and structuring Dementor motion behaviors.

## E. DIA — Motion

### 21 Mailchimp
Source: https://www.dia.studio/work/mailchimp
TAKE: motion as a system layer; remove decorative components that cannot scale; one behavior language from brand to product.
DON'T TAKE: mascot personality.
USE IN: motion system and onboarding.

### 22 IBM AWS
Source: https://www.dia.studio/work/ibm-aws
TAKE: variable typography, modular toolkit, repeated transitions, scale as one governing concept.
DON'T TAKE: gradients and IBM/AWS visual code.
USE IN: hero type pressure and responsive display typography.

### 23 Chaumont Biennale
Source: https://www.dia.studio/work/chaumont-biennale
TAKE: system-generated unexpected outputs curated by the designer; controlled unpredictability.
DON'T TAKE: memes as literal style.
USE IN: rare generative headline variations.

### 24 Nuits Sonores
Source: https://www.dia.studio/work/nuits-sonores
TAKE: translate rhythm into type/form; limited black-white-neon palette as a participation marker.
DON'T TAKE: rave particles/festival identity.
USE IN: ticker, event motion, acid as signal.

### 25 Google Expressive Captions
Source: https://www.dia.studio/work/google-expressive-captions
TAKE: observable behavior mapped to specific typographic treatments; explicit fallback rules.
DON'T TAKE: caption UI as visual style.
USE IN: motion specification and accessible alternatives.

## F. Dementor Ink — Proprietary layer

### 26 Shadow rebellion
TAKE: normal scene + one wrong fact; absurdity reads instantly.
DON'T TAKE: monster-first or horror storytelling.
USE IN: Home, About, onboarding interruptions.

### 27 Office throne
TAKE: ordinary office object receives absurd status; authority becomes a visual joke.
DON'T TAKE: gothic/fantasy detail as recurring brand language.
USE IN: Work / Control / editorial / merch.

### 28 Crowd / instruction
TAKE: social system shown through a group and one dissonant person.
DON'T TAKE: identical grotesque faces as a repeated style.
USE IN: Community, Information, Logic & Awareness references.

### 29 Head / maze
TAKE: strong full-page editorial metaphor.
DON'T TAKE: 'psychology = maze' as a universal shortcut.
USE IN: long reads and rare manifesto breaks.

### 30 Ink invasion / UI corruption
TAKE: Ink may cross borders, cover metadata, sit on lines and leave the viewport; UI itself remains disciplined.
DON'T TAKE: random grunge background or splatters everywhere.
USE IN: signature interaction on roughly 10–20% of screens.

## Control formula

Public Records builds the architecture.  
Actual Source systematizes.  
032c writes with editorial force.  
Mouthwash decides scale, rhythm and silence.  
DIA defines behavior.  
Dementor Ink breaks the already-finished system.

## Implementation order

Every new page follows:

1. Layout
2. Type
3. Content hierarchy
4. Composition
5. Motion
6. Ink

Never begin from an illustration or animation effect.

## New reference rule

A new website is added only if it solves a concrete problem better than the six canonical sources. Every new reference must include TAKE / DON'T TAKE / USE IN.
