# Dementor Club — Reference Responsibilities

Status: approved reference map
Updated: 2026-08-23

Этот файл фиксирует **откуда именно мы берём принципы** и предотвращает бесконтрольное смешивание визуальных систем.

## Public Records — архитектура

Reference role: cultural ecosystem architecture.

Take:
- dynamic homepage as current-programme interface;
- event-first information architecture;
- independent event pages;
- archive logic;
- coexistence of multiple cultural activities under one identity;
- content-led navigation.

Apply to:
- Home;
- Events;
- Archive;
- global information architecture.

Do not take:
- gallery sterility;
- excessive neutrality;
- calm premium tone.

## Actual Source — каталог

Reference role: index / catalog / metadata.

Take:
- list-first browsing;
- visible metadata;
- numbering;
- dense project indexes;
- hover previews on desktop;
- simple technical navigation.

Apply to:
- Projects index;
- Events archive;
- Merch;
- future Community index;
- footer/index navigation.

Do not take:
- total visual neutrality;
- catalog as the entire emotional identity.

## 032c — редакционная наглость

Reference role: editorial typography and verbal attitude.

Take:
- long meaningful headlines;
- strong hierarchy between kicker/headline/body/meta;
- statements as composition;
- editorial markers;
- large quotes;
- pages readable at several speeds.

Apply to:
- About;
- Manifesto;
- project stories;
- event stories;
- homepage statements.

Do not take:
- fashion-luxury aesthetic;
- red as club identity;
- typographic variety for its own sake.

## Mouthwash — композиция

Reference role: scale, whitespace, rhythm and media placement.

Take:
- one dominant thought per viewport;
- strong alternation of dense and quiet states;
- oversized media;
- asymmetry inside a disciplined grid;
- large intentional whitespace;
- connected content paths.

Apply to:
- Homepage;
- Project detail;
- Event detail;
- About;
- galleries.

Do not take:
- polished premium-brand smoothness;
- decorative empty space;
- product-render mentality.

## DIA Studio — движение

Reference role: behaviour and kinetic identity.

Take:
- variable typography as motion;
- repeatable behavioural rules;
- state reclassification;
- modular motion systems;
- generative variation under strict rules.

Approved Dementor motion behaviours:
1. Pressure.
2. Drift.
3. Reclassification.
4. Type Mutation.
5. Ink Intrusion.
6. Mechanical Ticker.
7. Controlled Generative Variation.

Apply to:
- Hero;
- Join/onboarding;
- section transitions;
- selected project/event moments.

Do not take:
- generic animation showcase;
- continuous glitch;
- motion without meaning.

## Dementor Ink — собственная грязь

Reference role: proprietary graphic disruption.

This is not a borrowed reference.

Take from our own approved drawings:
- nervous black ink;
- dry brush;
- splashes;
- unfinished line;
- normal scene + one absurd mutation;
- image crossing the otherwise strict grid.

Apply to:
- controlled visual interruptions;
- event/project visual scenes;
- section breaks;
- selected hover/tap previews;
- full-screen takeovers only rarely.

Do not allow it to become:
- horror;
- gothic fantasy;
- monster illustration system;
- wallpaper on every section.

## Required reference board

Maintain ~30 annotated screens/clips:

- 5 Public Records — architecture;
- 5 Actual Source — catalog;
- 5 032c — editorial;
- 5 Mouthwash — composition;
- 5 DIA — motion;
- 5 Dementor Ink — proprietary examples.

Every item must include:
- exact source/project/page;
- screenshot or clip;
- principle taken;
- intended Dementor use;
- explicit “do not copy” note.

## Evaluation rule for adding references

Before adding a new site, answer:

**What concrete design problem does it solve better than the existing six-source system?**

If there is no precise answer, it does not enter the official reference system.
