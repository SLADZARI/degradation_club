## GitHub хранит

- код;
- UI и дизайн-токены;
- контентные JSON/Markdown-файлы;
- технические спецификации;
- интеграции;
- deployment configuration;
- changelog;
- обязательные implementation rules для дизайна и подачи.

## Google Drive хранит

- Figma/PDF/экспорты дизайна;
- фото, видео и исходники;
- брендовые материалы;
- тяжёлые изображения;
- презентации;
- согласованные визуальные референсы;
- человекочитаемую утверждённую дизайн-документацию.

## Связь с веткой клуба

Контент сайта должен ссылаться на утверждённый материал из `dementor-club`. Если текст меняется по смыслу — сначала обновляется клубная ветка, затем сайт.

Если меняется правило публичной подачи — обновляется `dementor-club/brand/PRESENTATION_RULES.md`, затем `dementor-club-site/docs/DESIGN_PRESENTATION_GUIDE.md` и при необходимости Google Doc.
