# Google Drive ↔ GitHub

Основная папка клуба:

https://drive.google.com/drive/folders/1o5yPQdQ75zpzO0NBLhv26EpGHD_LPWMS

## Правило хранения

### GitHub
- концепция и структура клуба;
- утверждённые тексты;
- правила и процессы;
- контент-календарь;
- research notes;
- версии документов и changelog.

### Google Drive
- визуальные исходники;
- презентации и рабочие документы;
- фото/видео/аудио;
- бренд-материалы высокого разрешения;
- экспорт и материалы для внешнего использования.

## Связь с сайтом

Ветка `dementor-club` является source-of-truth для смыслов и утверждённого контента клуба. Ветка `dementor-club-site` использует только утверждённые версии материалов, ссылаясь на их Git path или ID.
